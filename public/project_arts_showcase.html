Web Development Project - Arts Showcase

This is the second capstone project as part of the "Complete Full-Stack Web Development Bootcamp" by Dr. Angela Yu at Udemy.

The goal of this project is to create a website using Node.js, Express.js, axios and EJS accessing a public API. The API from the Metropolitan Museum of Art was chosen. This project has demonstrated the use of EJS for server-side rendering and the interaction with Javascript altering the web page element appearances as well as the passing of data to and fro the server and the API. The web page appearance and the user interaction are also important aspects in this project.
